# Второе большое ревью кода (18 ноября)

Независимое ревью после второго обновления (этапы 9–17, код вырос почти вдвое, много этапов делалось параллельно).
Три ревьюера, каждый — своя зона; полные отчёты — в `docs/review2/`:

- `docs/review2/core.md` — основа: `main.js`, `core/`, `engine/`, `ui/`, `art/`, стили, сохранения и профили, автотест `dev/`;
- `docs/review2/features.md` — игровая логика: `features/`, `data/`, баланс;
- `docs/review2/places.md` — места и мини-игры: `locations/`, `interiors/`, `minigames/`.

## Общий вывод

Архитектура здоровая: слои соблюдены, циклов нет (`node dev/deps.js` — 224 модуля), состояние меняется только через
`core/actions.js`, старые критичные находки `docs/REVIEW.md` не вернулись, утечек в 29 мини-играх нет, все 10 карт связны,
лазеек «бесконечных денег» нет. Слабые места — края хранилища (переполнение, Safari, испорченное сохранение, две вкладки),
окна, которые при ошибке замораживают игру, баги на стыке «способ передвижения + переход между сценами + сохранение»
и большая копипаста (призовые игры ×11, поездка в затемнении ×7, каркас мини-игр ×19, помощники автотеста ×10–28).
