# Run, Hamster, Run! 🐹

Уютная браузерная игра-песочница про хомячка, который живёт на большой вилле у моря.
Где-то между *Stardew Valley* и *Toca Boca*: свой дом, сезоны, друзья, наряды, готовка
и задания из почтового ящика — и при этом нельзя проиграть.

Идею придумала дочь, дизайн-документ лежит в [`docs/GDD.md`](docs/GDD.md).

## Как играть

- **Нажми** на любое место — хомячок пойдёт туда. На компьютере можно ещё стрелками / WASD,
  клавиша **E** (или пробел) — «потрогать» то, что рядом.
- Каждое утро в **почтовом ящике** у двери виллы лежит письмо с заданием.
  За задание — наклейка в альбом и иногда подарок-сюрприз.
- На вилле три этажа и лифт: спальни, кухня, ванная, сауна, джакузи, бассейн. Нажимай на всё подряд!
- Кнопка **🔨 «Обустроить»** — перетаскивай мебель, доставай новую из кладовки.
- В городе: три ТЦ (одежда, мебель, продукты), бутик, салон красоты, кафе, ресторан,
  бассейн, школа, больница, Дом моды, смотровая площадка, банк, пляж и пирс.
- Чтобы наступил следующий день, ложись спать. В месяце 3 дня, в году 12 месяцев и 4 сезона.

Игра сохраняется сама — в браузере на этом устройстве.
Музыка и звуки включаются и выключаются в меню ⚙️.

## Запуск

Сборка не нужна: это обычные HTML + CSS + JavaScript (ES-модули), без зависимостей.

```bash
python3 -m http.server 8000
```

и открыть <http://localhost:8000>. Просто открыть `index.html` двойным щелчком не получится —
браузеры не загружают ES-модули с `file://`.

### GitHub Pages

Settings → Pages → *Deploy from a branch* → ветка `main`, папка `/ (root)`.
Через минуту игра будет доступна по адресу `https://<user>.github.io/run-hamster-run/`.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html`, `css/style.css` | Страница и оформление интерфейса |
| `js/main.js` | Заставка, главный цикл, ввод, HUD |
| `js/game.js` | Состояние игры, сохранение, календарь, инвентарь |
| `js/data.js` | Таблицы: одежда, мебель, еда, рецепты, друзья, задания |
| `js/hamster.js` | Рисование хомячка и одежды |
| `js/props.js` | Рисование мебели |
| `js/world.js` | Город, двор и пляж (вид сверху), поиск пути, жители |
| `js/villa.js` | Вилла в разрезе, лифт, режим обустройства |
| `js/tower.js` | Хомяк-Тауэр: холл, поездка на лифте, смотровая площадка |
| `js/dive.js` | Подводный мир: ныряние, жители моря, жемчуг, затонувший корабль |
| `js/features.js` | Магазины, шкаф, салон, готовка, гости, почта и задания, сон |
| `js/ui.js` | Окна, диалоги, подсказки |
| `js/audio.js` | Звуки, фоновая музыка и окружение — всё синтезируется, без файлов |
| `js/minigames/` | Мини-игры: плавание, рыбалка, учительница, доктор, шеф-повар, показ мод |
| `dev/` | Страницы для разработки (лист с хомячками, запуск мини-игр по отдельности) |

Хочется добавить новую одежду, мебель, блюдо, друга или задание — почти всегда достаточно
дописать строчку в `js/data.js`.
